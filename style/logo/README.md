# Logo

Put the HAW Kiel logo here – **file name: `haw-kiel-logo.pdf`**
(alternatively `.png` or `.jpg`). A vector PDF looks best in print.

As long as no file exists, the template automatically shows a placeholder box
("HAW Kiel – Logo placeholder") and prints a warning when compiling. The
document therefore builds without a logo as well.

- The official logo is provided by the university (press / corporate design
  downloads or intranet). It is protected by trademark law – only use it
  according to the university's guidelines. **Do not commit it to a public
  repository.**
- Different file name or location: set `\logoFile{\StyleDir/logo/my-logo}`
  (without extension) in `configuration.tex`.
- Size: `\logoHeight{18mm}`.
- No logo at all: `\Logo{no}`.

---

**Deutsch:** Das Logo der HAW Kiel als `haw-kiel-logo.pdf` (oder `.png`/`.jpg`)
hier ablegen. Ohne Datei erscheint ein Platzhalter. Das Logo ist markenrechtlich
geschützt und gehört nicht in ein öffentliches Repository.
